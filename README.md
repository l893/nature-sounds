# Nature Sounds (Webpack + Vanilla JS)

Приложение воспроизводит природные шумы и меняет фон в зависимости от выбранной сцены. Есть регулятор громкости и кнопки переключения звуков. При повторном нажатии на кнопку — пауза/продолжение. Одновременно играет только один звук.

## Технологии

- Webpack 5 (common/dev/prod)
- webpack-dev-server
- SASS/SCSS
- ESLint (eslint:recommended)

## Скрипты

- `npm run dev` — локальная разработка на http://localhost:5173
- `npm run build` — production‑сборка в `dist/`
- `npm run lint` / `npm run lint:fix` — проверка стиля кода

## Запуск

```bash
npm i
npm run dev
```
